# New York's CitiBike trips in 2022
## Overview
A multi-page interactive dashboard built with Streamlit to explore and visualize Citi Bike trip data across New York City in 2022. It highlights seasonal trends, user behavior, and ride duration patterns to support strategic planning and operational decisions.
## Tools & Technologies
- Python (Pandas, Seaborn, Plotly)
- Streamlit (multi-page layout)
- GitHub (version control and deployment)
- Unsplash (image assets)
- HTML embedding (interactive map)
  ## Dashboard Features
- Sidebar filters for season and user type
- Bar charts, line plots, and FacetGrid visualizations
- Embedded HTML map showing trip density
- Summary page with strategic recommendations
